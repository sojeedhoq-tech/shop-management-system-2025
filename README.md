# 🏪 Shop Management System

একটি আধুনিক এবং সহজ শপ ম্যানেজমেন্ট সিস্টেম যা দোকানের দৈনন্দিন হিসাব-নিকাশ পরিচালনা করে।

## ✨ প্রধান ফিচার

- 📊 **বিক্রয় ও ক্রয় রেকর্ড** - প্রতিটি লেনদেনের বিস্তারিত রেকর্ড
- 📦 **স্টক ইনভেন্টরি** - পণ্যের স্টক পরিচালনা এবং ট্র্যাকিং
- 💰 **বাকির হিসাব** - গ্রাহক এবং সরবরাহকারীর বাকি ম্যানেজমেন্ট
- 📈 **লাভ-ক্ষতির রিপোর্ট** - বিস্তারিত আর্থিক বিশ্লেষণ
- 🧾 **ডিজিটাল ক্যাশমেমো** - স্বয়ংক্রিয় রসিদ তৈরি
- 📱 **মোবাইল-ফ্রেন্ডলি** - যেকোনো ডিভাইস থেকে অ্যাক্সেস করুন
- 🔒 **সম্পূর্ণ নিরাপদ** - এনক্রিপ্টেড ডাটা এবং সিকিউর অথেন্টিকেশন

## 🛠️ প্রযুক্তি স্ট্যাক

### Backend
- **Node.js** - Runtime Environment
- **Express.js** - Web Framework
- **MongoDB** - Database
- **JWT** - Authentication

### Frontend
- **React** - UI Library
- **Axios** - HTTP Client
- **Tailwind CSS** - Styling
- **React Router** - Navigation

## 🚀 শুরু করুন

### Prerequisites
- Node.js (v14 বা তার উপরে)
- MongoDB
- npm বা yarn

### Installation

#### Backend Setup
```bash
cd backend
npm install
cp .env.example .env
# .env ফাইলে MongoDB URL এবং অন্যান্য কনফিগ যোগ করুন
npm start
```

#### Frontend Setup
```bash
cd frontend
npm install
npm start
```
